# 上线前准备清单（2026-10-07）

> 对应 D8 的 4 张票：SYS-PROD-001（生产部署）· SYS-RELEASE-001（小程序提审上线）· SYS-BACKUP-001 · SYS-MANUAL-001。
> 外部缺口台账见 `doc/handover/d8-blockers.json`（B1–B6），本文是把它们落成「谁去办、要什么材料、等多久」。
> 合同分工：**云服务器 / OSS / 域名 / ICP 备案以乙方（添达）名义**（第二条第 3 款）；**小程序注册、认证、小程序备案以甲方主体**（第四条 1(3)），认证费甲方直付。

## 0. 两条关键路径，都按周计，今天就并行启动

```
甲方线：注册小程序 → 微信认证（300 元，数个工作日）→ 小程序备案（平台初审 1-2 工作日 + 湖北管局 1-20 工作日 + 12381 短信 24h 内核验）
                                                                                      ↘
                                                                                        提审 → 发布
                                                                                      ↗
乙方线：阿里云企业实名 → 买域名并实名 → 买 ECS（包年包月 ≥3 个月）→ ICP 备案（阿里云初审 1-2 + 湖北管局 1-20 工作日 + 短信核验）
        → 配合法域名、部署生产、HTTPS → 上线后 30 日内公安联网备案
```

- **小程序没有完成备案不能上架**；**微信合法域名要求域名已 ICP 备案**——两条线任何一条没走完都上不了线。
- 最乐观 2 周，常见 3-4 周。10 月 8 日管局恢复上班，越早提交越好。

## 1. 甲方要准备的（按办理顺序）

### 1.1 先定下来的三件事（不定就没法开始注册）

| # | 事项 | 说明 |
|---|---|---|
| A1 | **用哪个主体注册**（OQ-11） | 「类器官研究中心」如果不是独立法人，就用**湖北江夏实验室**的主体注册。要确认主体证件是哪一种：事业单位法人证书 / 营业执照 / 民办非企业登记证书——决定注册时选的主体类型。若走上级审批，请尽早发起 |
| A2 | **小程序名称**（OQ-6） | 2-30 个字、全平台唯一。**备案时会提交名称，备案后再改要走变更备案**，所以先定准。建议带上单位简称，例如「江夏实验室类器官送检」（以微信查重结果为准） |
| A3 | **谁当管理员** | 甲方一位**长期在岗**的工作人员。之后取 AppSecret、改服务器域名、生成上传密钥、加成员都要**管理员微信扫码**。不建议由乙方当管理员——账号归甲方 |

### 1.2 注册 + 微信认证要的材料

| 材料 | 要求 |
|---|---|
| 一个邮箱 | **没注册过**微信公众号、小程序、开放平台的邮箱，建议用单位邮箱 |
| 管理员身份证 + 微信 | 管理员本人身份证号；其微信须**已绑定本人银行卡**（扫码验证用） |
| 主体证件 | 事业单位法人证书（或营业执照）彩色扫描件；复印件须盖红章 |
| 法定代表人（单位负责人）信息 | 姓名、身份证号 |
| **认证申请公函** | 微信后台下载模板，**加盖红色实体公章（电子章无效）+ 运营者手写签名**，签名须与填写的运营者姓名一致 |
| 对公账户信息、开票抬头 | 认证支付与开发票用 |
| 认证费 300 元/年 | 甲方直接付给微信（合同已约定）。每年要续，到期不续手机号登录会用不了 |
| 小程序基本信息 | 名称（A2）、头像（一张方形 Logo）、简介（≤120 字，我们可起草）、服务类目（建议**工具 › 办公**一类，**不要选医疗**——医疗类要前置审批资质） |

### 1.3 小程序备案要的材料（湖北管局）

| 材料 | 要求 |
|---|---|
| 主体负责人 | 原则上是**法定代表人 / 单位负责人**：身份证正反面**彩色原件照片**（不收复印件、翻拍件）、手机号、邮箱 |
| 小程序负责人 | 可以就是管理员：身份证正反面彩色原件照片、手机号、应急联系电话、邮箱；**本人手机上做人脸核验** |
| 授权委托书 | 小程序负责人不是法定代表人时需要，**盖公章**（湖北对 ICP 备案有这条要求，小程序备案按同样口径准备） |
| 互联网信息服务承诺书、备案真实性核验单 | 备案流程里下载，签字、盖章后上传 |
| 前置审批 | 选「不涉及」。说明口径：本小程序是实验室与合作单位之间的 B 端送检工具，不面向患者，不提供诊疗服务 |
| **两位负责人的手机要能收短信** | 管局审核通过前会从 **12381** 发核验短信，**24 小时内**到 beian.miit.gov.cn 完成核验，超时自动驳回 |

### 1.4 认证完成后，交给乙方的东西（开发对接）

| # | 事项 | 怎么给 |
|---|---|---|
| D1 | **AppID** | 微信后台「开发管理 → 开发设置」里直接可见，发给乙方即可 |
| D2 | **AppSecret** | 管理员扫码生成，**单独私发**，不要发在群里。乙方只存放在服务器上 |
| D3 | 把乙方（Kevin 的微信号）加为**项目成员**：开发者权限 + 开发设置权限，并加为体验成员 | 管理员在「成员管理」里操作 |
| D4 | 小程序代码上传密钥 + IP 白名单 | 需要管理员扫码，约 10 分钟，**约个时间我们远程一起操作**；顺便一起配服务器域名和隐私保护指引 |
| D5 | 隐私政策、用户协议要写的单位信息 | 单位全称、地址、个人信息联系人、联系电话或邮箱（用于「联系实验室删除数据」） |
| D6 | 生产首个管理员的手机号（B4） | 上线后用它在工作台登录并给其他内部人员授权 |
| D7 | 一位真实的合作单位用户 | 上线当天用真实微信走一遍登录 + 送检，作为线上冒烟 |

### 1.5 甲方可能会问到的费用

- **手机号快速验证**：微信 2023-08 起收费，每次成功调用 0.03 元，每个小程序有 1000 次体验额度。本系统只在首次登录时取一次手机号，用量很小；额度用完后要在微信后台**用甲方账号购买资源包**（OQ-5：费用发生在甲方账号上，合同未单列，建议在消息里提一句，免得到时意外）。
- 小程序认证 300 元/年（合同已约定，甲方直付）。

## 2. 乙方（Kevin）自己办的：阿里云 + 域名 + ICP

### 2.1 账号

- 阿里云账号要**以武汉市添达信息技术服务有限公司做企业实名认证**（营业执照 + 法定代表人扫脸，或对公打款）。合同写的是乙方名义；甲方付的 2000 元/年也要开公司发票。
  - 现有那台测试 ECS（`118.178.109.11`）所在的账号如果是个人实名，**不要直接拿它备案**：要么新开一个企业账号，要么把它升级为企业认证（升级不可逆，想清楚再点）。
- 备案主体 = 添达 → 走**湖北管局**。

### 2.2 买什么（都在同一个企业账号下）

| 资源 | 规格 | 备案相关的硬要求 |
|---|---|---|
| ECS | 2 核 4G、系统盘 ≥40G + 另挂数据盘（`doc/ops/部署手册.md` §1.2 的容量账） | **中国内地地域、包年包月且累计 ≥3 个月、要有公网带宽**——否则拿不到备案服务码。免费试用 / 按量付费的都不行。直接买 1 年 |
| OSS | 与 ECS **同地域**，**私有**读写桶；RAM 子账号只授这一个桶 + 生命周期（B1） | — |
| 域名 | 新买一个 `.com` / `.cn`，**持有者实名为添达公司** | 湖北：**域名持有者须与主办单位名称或法定代表人一致**，有效期 >30 天。实名审核通过后才能提交备案 |

> ⚠️ **`tianda.studio` 不建议用作生产域名**：没查到 `.studio` 在工信部批准的可备案后缀里（2024-11 时批准了 159 个后缀，没有找到完整清单核对）。在阿里云备案系统里一填就知道。即使能备案，生产也最好单独用一个域名，和测试环境分开。

### 2.3 ICP 备案（湖北管局的特殊要求）

- **主体负责人必须是添达的法定代表人**，不是法定代表人不能备案。
- 网站负责人填法定代表人；如果填别人，要传**法定代表人授权委托书**。
- 材料：营业执照原件彩照、法定代表人身份证原件彩照、网站负责人身份证原件彩照，网站负责人**人脸核验**（阿里云 App）。
- **网站名称**：按「单位互联网信息服务命名要求」取一个和添达经营内容相关的中性名称。**不要用甲方单位名**——主体是添达、名称却是别家单位，管局容易要求补充说明或直接驳回。网站内容是登录后使用的业务系统，没有对外公开内容。
- 流程：阿里云初审 1-2 工作日（会打电话核实）→ 管局 1-20 工作日 → 12381 短信 24h 内核验。
- **ICP 通过后 30 日内做公安联网备案**（全国互联网安全管理服务平台，选单位 / 法定代表人登录），通过后把公安备案号也放到网页工作台的页脚（与 `LQG_ICP_LICENSE` 同处）。系统有登录和用户提交内容，按「交互式」如实填写。

### 2.4 ICP 通过之后（接回 D8 票）

1. `doc/ops/部署手册.md` §1 → §11：部署生产、acme.sh 签证书、`gen-secrets.sh`、OSS 初始化。
2. 微信后台（与甲方约的 D4 那次一起）：
   - 服务器域名：request / uploadFile / downloadFile 都填 `https://<生产域名>`（SYS-RELEASE-001 口径 3）；
   - 用户隐私保护指引：如实声明**手机号**、**相机 / 相册**；没用到的（位置、剪贴板等）不勾；
   - 上传密钥 + IP 白名单：现在 CI 走测试机固定 IP 转出，生产 appid 的白名单也要加上这个 IP（或者加生产机 IP，看到时从哪台机器发）。
3. 体验版回归 → 提审 → 发布 → 线上冒烟，逐项记录到 `doc/ops/小程序发布清单.md`。

## 4. 可以直接发给甲方的消息

> 老师您好，系统功能已基本完成，接下来要准备上线。微信规定小程序必须由使用单位以自己的名义注册、认证、备案，这部分需要贵中心办理，我们全程协助。整个流程要经过微信审核和湖北通信管理局审核，**一般 2-4 周**，所以想请您这两天先启动：
>
> **一、先定三件事**
> 1. 用哪个单位名义注册：如果类器官研究中心不是独立法人，就用湖北江夏实验室的名义（请告知证件是事业单位法人证书还是营业执照）；
> 2. 小程序名称（例如「江夏实验室类器官送检」，备案后再改比较麻烦）；
> 3. 指定一位长期在岗的老师当管理员，后续几个关键操作都需要他 / 她用微信扫码。
>
> **二、注册和认证需要**
> - 一个没注册过微信公众号 / 小程序的单位邮箱；
> - 管理员的身份证号，管理员的微信需要绑定本人银行卡；
> - 单位证件（事业单位法人证书或营业执照）彩色扫描件；
> - 法定代表人（单位负责人）姓名和身份证号；
> - 认证申请公函（微信后台下载模板，盖红色公章 + 管理员手写签名）；
> - 对公账户信息；认证费 300 元/年，直接付给微信；
> - 一张方形 Logo。简介我们来起草。
>
> **三、小程序备案需要**
> - 法定代表人和小程序负责人（可以就是管理员）的身份证正反面**原件彩色照片**、手机号、邮箱；
> - 负责人不是法定代表人的，需要一份盖公章的授权书（模板我们提供）；
> - 承诺书、核验单各一份，签字盖章；
> - 负责人本人要在手机上做一次人脸识别；审核快结束时会收到 **12381** 发的短信，**需要 24 小时内**点链接完成核验，过了时间会被退回。
>
> **四、认证完成后**
> 请把 AppID 发给我，AppSecret 单独私发；把我的微信加为开发者；另外约 10 分钟远程，一起完成扫码配置。
> 还请提供：隐私政策里要写的单位全称、地址、联系人和电话；上线后第一个管理员的手机号。
>
> 另外提前说明一项小费用：手机号一键登录按微信规定每次成功调用 0.03 元，每个小程序有 1000 次免费额度。本系统每个人只在第一次登录时调用一次，用量很小，额度用完后在贵中心的微信后台充值即可。
>
> 服务器、域名和网站备案由我们这边办理（合同约定的云资源费已包含），和您这边同时进行。注册过程中哪一步卡住，随时截图发我。
