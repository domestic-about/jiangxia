## 第一条 软件开发的内容和目标

1. 开发内容：乙方负责开发“类器官送检与样本管理系统（V1.0）”，包含以下交付端，功能明细及业务规则见附件《系统功能清单》：
    - 微信小程序（合作单位与甲方内部人员使用）：首页四张表的在线填写（样本记录信息表、类器官收样记录、石蜡包埋送样记录、-80 冻存记录）与拍照识别预填；文档页（质控等结果文档的列表、预览、Word 或 PDF 单份或合并下载）；“我的”页；微信登录与手机号授权。
    - 网页工作台（仅甲方内部人员使用）：样本总表的批量筛选、查询与 Excel 导出；样本质控表、类器官质控表、类器官质量评分表的在线编辑（含图片与附件）；-80℃ 冻存超期提醒与出入库登记；内部人员授权管理。
    - 后端服务与数据库。
2. 开发目标：乙方按甲方要求完成上述系统研发，打通合作单位送检、甲方收样处理、质控文档出具并同步给送检方、冻存管理的业务链路。开发与测试在乙方自有的测试服务器上进行，确认上线后部署到乙方代为购买的云服务器上。
3. 不包含内容：以下内容不在本合同范围内，甲方如有需要，双方另行协商并收费：
    - 安卓、iOS 等 APP 的开发与应用市场上架；
    - 甲方历史 Excel 台账等存量数据的批量导入；
    - 药敏实验数据管理与药敏报告；
    - 与医院信息系统等第三方系统的对接；
    - 本合同第二条第 5 款所列、由甲方直接承担的第三方费用。

| 小程序 · 登录与权限 | 微信登录与授权 | 统一微信登录并授权手机号；内部人员由甲方在网页工作台按手机号授权；内部人员以外均为外部人员 |
| 小程序 · 登录与权限 | 可见范围 | 外部人员可以看到与自己样本相关的全部内容，如质控结论、评分、石蜡包埋情况；同单位不同组看不到彼此的样本，同组可以看 |
| 网页工作台 | 样本总表 | 所有样本集中在一张表里，可按来源单位等条件批量筛选、查询；外部人员填写的信息实时进入样本总表 |
| 网页工作台 | Excel 导出 | 四张表均可导出为 Excel，内部人员可导出全部样本信息 |
| 网页工作台 | 内外部区分与切片染色提示 | 按提交人区分内部样本与外部样本；收样记录中提示该样本做过哪些切片、染色 |
| 网页工作台 | 质控文档编辑 | 样本质控表、类器官质控表、类器官质量评分表由内部人员在网页上编辑，可上传图片与附件；完成后外部人员可在小程序查看自己样本对应的文档 |
| 编号与冻存 | 内部编号与冻存代数 | 一个样本从收样到冻存使用同一内部编号；冻存时记录代数（如 P2、P7）；对外部人员显示甲方另取的石蜡块编号 |
| 编号与冻存 | 冻存超期提醒与出入库追溯 | -80℃ 冻存超过两周提示转入液氮；从液氮或 -80℃ 取走需登记，支数相应增减，全程可追溯 |
| 石蜡包埋 | 染色与 marker 选择 | 染色：HE / IF / IHC / 其他 / 无染色；marker 表达：阴性 / 弱表达 / 强表达 |
| 部署与运维 | 云服务器部署与备份 | 在乙方代为购买的云服务器上以 Docker 部署后端、PostgreSQL 数据库、网页工作台；数据库每日自动备份 |

### 二、待甲方确认的事项

| 事项 | 乙方建议 |
|--------------------------------------------|--------------------------------------------|
| 外部用户组别的划分与维护 | 由甲方在网页工作台维护组别，外部用户首次提交时选择所属单位与组别，甲方核验后生效 |
