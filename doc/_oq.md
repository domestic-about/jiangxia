## 状态枚举

| 状态 | 含义 |
|---|---|
| Open（表内标 ⏳） | 待对方答；没有可先行的口径，或先行口径不足以完成该 ticket |
| Fallback adopted（表内标 🟢） | 按 Fallback 先行实现（对方后答不同 → 走变更记录改） |
| Closed（表内打勾） | 有明确答案且已落地（closed_by 必填：ADR-NNNN 或 file:line） |
| Dropped（表内标 ❌） | 问题不再成立（写一句为什么） |
