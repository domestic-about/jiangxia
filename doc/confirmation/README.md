## 需要您提前知道的 9 件事（不是问题，是怕到时候意外）

1. **小程序里的「下载」长这样**：微信小程序不能把文件直接存到手机文件夹。点「打开」会用微信自带的查看器打开 Word / PDF，右上角菜单里可以保存或用其他应用打开；点「发送到微信」可以把文件发给自己或同事。网页工作台上是正常的下载。
2. **预览为什么能和 Word 一模一样**：预览图、Word、PDF 是同一份文件转出来的。服务器上没有「宋体」，会换成一款很接近的开源宋体，所以和您电脑上的 Word 会有细微差别——以我们发您确认的样张为准。
3. **「细胞活率测定」那一格**：导出的 Word 里印的是附件的文件名，不是可以双击打开的图标；附件本身在预览页下面可以点开。
4. **供体姓名、住院号、患者编号在数据库里是加密存的**。代价是：在工作台里按这三项查找时要输入完整内容，不能只输一半。
5. **小程序列表里供体姓名显示成「刘\*\*」**，点进详情才是全名（防止旁边的人瞥见）。工作台里不遮挡。
6. **冻存超两周的提醒只在系统里**：网页工作台首页与左侧菜单的红色数字、冻存列表置顶标红（小程序「我的 → 内部管理」里的冻存表也一样标）。小程序首页不放数字。不会发微信消息或短信。
7. **已核验的记录，合作单位不能自己再改**：待核验或无效时，合作单位可以在「我的 → 历史编辑记录」里改自己送的记录；您核验为有效之后，有错由中心内部人员修改——自己录的在小程序「我的 → 历史编辑记录」里改，其余在网页工作台改（都会记下是谁、什么时候改的）。如果您希望合作单位也能改已核验的，告诉我们。
8. **合作单位能填三张表**：样本记录信息表、类器官收样记录、石蜡包埋送样记录，提交后都要您核验；-80 冻存记录只有内部人员能看到。合作单位填类器官收样记录只填来源单位、类器官类型、备注；填石蜡包埋送样记录只选自己送检过的样本，再填样本类型、类器官来源类型。这样划分是我们先定的，不合适在确认单 02、03 里勾出来。
9. **小程序和网页工作台的分工**：小程序首页用来填表；「我的 → 历史编辑记录」找回自己填过的记录并修改（列的是记录，不是每一次修改的明细）；内部人员的「我的 → 内部管理」看四张表的全部记录、筛选、导出，但不在里面改。核验、冻存的取走 / 补入 / 转液氮 / 改删登记，以及修改别人录的记录，都在网页工作台做。
