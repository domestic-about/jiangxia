| 页面 | 关键字段 / 选项 | 关键业务规则 | 甲方确认 |
|---|---|---|---|
| **小程序登录页** | 一个按钮：微信手机号快捷登录；勾选《用户协议》《隐私政策》 | ① 不分「内部登录 / 外部登录」，所有人同一个入口；② 必须授权手机号才能进；③ 系统按手机号判断身份，**用户自己选不了**自己是内部还是外部 | ☐ 覆盖 / ☐ 有问题： |
| **工作台 · 内部人员授权** | 姓名、手机号、角色〔内部人员 / 实验室管理员〕、工作台初始密码、是否已登录过小程序 | ① 您在这里按手机号加人，加了就是内部人员；② 这个人如果之前已经用小程序登录过，会把他原来的账号升级为内部，不会变成两个账号；③ 撤销授权后他立刻变回外部，当场被踢下线；他以前录的样本不受影响；④ 只有管理员能授权别人 | ☐ 覆盖 / ☐ 有问题： |
| **工作台 · 来源单位与组别** | 单位名称、组别名称、状态〔启用 / 待核验 / 停用〕、该组已核验人数 | ① 同一个单位里组别名不能重复；② 停用后小程序里选不到了，已经在这个组的人不受影响 | ☐ 覆盖 / ☐ 有问题： |
| **工作台 · 外部用户** | 姓名、手机号、单位、组别（自己填的会标出来）、核验状态〔未填写 / 待核验 / 已核验 / 已驳回〕、送过几个样本、最近登录 | ① 核验通过后，他才能和同组的人互相看样本；② 他自己填的新单位 / 新组别，核验时您选「新建」或「归到已有的某个组」；③ 驳回要写原因；④ 他之后自己改了单位或组别，会重新变成待核验 | ☐ 覆盖 / ☐ 有问题： |
| **小程序 · 我的**（所有人） | 所有人：历史编辑记录；合作单位多一行「单位与组别」（显示核验状态）；内部人员多一个「内部管理」板块（四张表：查看、筛选、导出，点一行进详情可修改） | ①「内部管理」只给内部人员，合作单位看不到这个板块；② 历史编辑记录的规则见确认单 02 | ☐ 覆盖 / ☐ 有问题： |
| **小程序 · 我的 → 单位与组别**（合作单位的人） | 姓名、单位、组别（列表里没有可以手填） | 保存后显示「待核验」，并说明核验通过后可与同组同事互看样本 | ☐ 覆盖 / ☐ 有问题： |

**本板块整体规则（跨页）**：
- **内部人员**（您在工作台授权的）：小程序首页能填全部四张表；「我的 → 内部管理」里能看全部记录、筛选、导出；能登录网页工作台，核验、冻存取用登记和修改别人录的记录都在那里做。
- **外部人员**（其他所有人，不需要您提前开通）：小程序首页有三张表可以填——样本记录信息表、类器官收样记录、石蜡包埋送样记录（**没有 -80 冻存记录**）；只能改**自己提交的**、还没核验或无效的记录；在「我的 → 历史编辑记录」看得到自己和**同组已核验同事**送的记录。**登不上网页工作台。**
- 同一个单位、不同组的人，互相看不到。同组但还没核验的人，也看不到别人的。
- 外部人员能看到的内容：送检信息和核验结果、石蜡包埋情况（用石蜡块编号标识；自己交的送样核验前也看得到；**含操作人与包埋人**——2026-09-18 按您的意见放开）、已完成的三份质控文档（含评分）。**看不到**：冻存信息。
- 内部编号默认也不对合作单位显示（用送检单号指代）。2026-09-18 按您的意见，这件事做成了一个**开关**：中心内部人员在工作台「系统管理 → 参数设置」里打开，合作单位页面上就显示内部编号，**默认是关的**。
- 已经核验为「有效」的样本，外部人员不能再改。
