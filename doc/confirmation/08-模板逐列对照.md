## 五、三份 Word 文档：预览和下载跟模板一样吗

**一样。做法是直接拿您给的 .docx 原件当模板往里填内容**，不是照着重新画一份——所以字体、表格线、行高、页脚那句注释都是您模板里的样子。填了内容的格子文字一律居中；字多时这一格自动缩小字号，格子高度不变（缩到最小还放不下才让这一行长高，文字不截断）。预览看到的页面图片、下载的 Word、下载的 PDF 是同一份内容转出来的。

| 模板 | 模板里的项 | 谁填 | 说明 |
|---|---|---|---|
| **样本质控表** | 患者编号 | 中心 | 编辑页填（图 17） |
| | 来源单位 / 患者姓名 / 性别 / 收样时间 / 处理时间 / 操作人 / 内部编号 | 自动 | 从样本记录带出，不用再填一遍 |
| | 取样部位 / 取样方式 / 临床诊断 · 既往治疗 | 中心 | 编辑页填 |
| | 收样描述 | 中心 | 编辑页填，默认已经填好模板里那句话，可以改 |
| | 细胞活率测定 | 中心 | 传附件；**Word 里这一格和您的模板一样嵌着附件**（文件图标 + 文件名，在电脑上双击打开；附件大于 20MB 时只印文件名）；PDF 和微信 / 手机预览里打不开嵌入对象，显示图标和文件名，附件在预览页下方可以直接点开 |
