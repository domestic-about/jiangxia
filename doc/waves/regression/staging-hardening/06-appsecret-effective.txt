# AppSecret 生效的判别式（2026-09-28）
# 时间：2026-09-28 08:49:26 +0800
# 环境：https://songjian.tianda.studio（profile=test，mockLogin=false）

判别式：同一个「非 mock 的假 code」请求 /auth/login，看微信回哪个错误码：
  · 没配 appid/secret → 41002 missing appid / 41001 missing appsecret
  · 配了但 secret 错 → 40125 invalid appsecret
  · **配对了 → 40029 invalid code**（微信真的去校验了 code，只是假 code 必然无效）

本环境实测：
  · 配 AppSecret **之前**（仅 appid）：41002 —— 「微信登录失败：错误代码：41002, 错误信息：缺少 appid 参数」
  · 配 AppSecret **之后**：
      {"code":500,"msg":"微信登录失败：错误代码：40029, 错误信息：code 无效，微信原始报文：{\"errcode\":40029,\"errmsg\":\"invalid code hint: [yDNeFdvvk-W13dIA] rid: 6ab9b997-425fca9c-412d0d6d\"}","data":null}

结论：40029 证明 appid+secret 被微信接受（真实 wx.login 的 code 现在能换出 openid）。
      同一请求现在也证明 **mock 已失效**：mock: 前缀不再被当成 mock，而是当普通 code 送去微信。
