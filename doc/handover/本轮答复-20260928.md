## 1. 拍照识别微信小程序有对应的 API 吗 —— **有，但不建议用它**

- **微信自己有 OCR**：`/cv/ocr/comm`（通用印刷体）+ 身份证 / 银行卡 / 营业执照 / 行驶证 / 驾驶证 / 菜单。
- **但两条不合适**：① 它**偏印刷体，没有手写体专项**，而甲方的样本要求里含 ≥3 张手写；② 自 2020-04-01 起全面计费，**免费额度只有 100 次/天**。
- **更合适的是腾讯云 OCR**：`通用印刷体识别` 与 `通用手写体识别` **各 1000 次/月免费**、当月有效、每月自动发放，试用期足够。
- 本项目的识别器是**可插拔**的（`OcrProvider` + 工厂 + 启动护栏 + 选择口径单测都已就位），**只差写一个适配器类 + 一把密钥**，不动任何已验收的业务代码。
- **需要你给的**：一组腾讯云 `SecretId/SecretKey`（子账号、只要 OCR 调用权限）→ 我实现 `TencentOcrProvider` 并在测试环境用真实样本跑准确率留证。或者一时拿不到，就按兜底给甲方一句书面说明「试用期先手填」。
- 另请**向甲方要 10 张以上真实样本照片（含至少 3 张手写）** —— 这是合同第 2 行的验收判据素材。
- 详细对比与依据链接：`doc/handover/OCR选型答复-20260928.md`
