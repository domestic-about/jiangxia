## 4. 还缺一样：AppSecret（不是上传密钥）

- **上传密钥**（你给的 `.key`）= 允许「往微信传代码」，只管上传。
- **AppSecret**（开发设置里的那串）= 后端拿它换 openid，是**真实微信登录**的前提。

没有 AppSecret 时，小程序里的真实登录走不通，所以 **mock 登录必须继续开着** —— 也就是台账 #346 那条公网风险还在
（知道测试环境网址的人能用 mock 登进演示账号）。你把 AppSecret 给我，我就：配 `LQG_WX_SECRET` → 关掉 mock（一行开关，**已实测有效**）
→ 验真实微信登录 → 再复验那几条依赖 mock 的断言。
