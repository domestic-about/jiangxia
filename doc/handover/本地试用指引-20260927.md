## 2. 建议的演示路径（一条外部样本的完整一生）

1. **小程序 H5** 以「外部人员」登录 → 首页点「样本记录信息表」→ 填一条并提交（可试「拍照识别」栏——见 §4 限制）。
2. **工作台** lqgadmin 登录 → 样本记录信息表 → 找到刚提交那条（待核验）→ 核验（判有效给内部编号）。
3. 工作台 → 石蜡包埋：核验时可在抽屉里一并补填工序/染色（**判无效时抽屉里改的实验室补填项不会保存，界面会明说**）。
4. 工作台 → 质控文档编辑：三份文档（样本质控表 / 类器官质控表 / 类器官质量评分表）→ 传图、评分 → 预览 → **完成并同步**。
5. **小程序 H5** 外部人员 → 我的 → 历史编辑记录 / 文档页签：看到状态变化、能预览（顶部三份切换、点缩略图**看原图**）、能下载（打开后右上角可存，或发送到微信）。
6. 工作台首页：**五张待办卡片**（待核验组织 / 待核验类器官 / 待核验石蜡包埋 / 冻存超期 / 待核验外部用户）+ **一张「渲染失败与缺图」卡片**（点开是清单抽屉，不是跳调试页）、侧边菜单角标。
