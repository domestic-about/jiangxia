## 要做什么（合同附件《系统功能清单》14 行，一条不多）

1. **小程序**（合作单位 + 内部人员）：三个页签——首页放表的填写入口（内外部同一个样子、没有数字：内部四张，外部三张、没有 -80 冻存记录；点进去就是填写——Kevin 2026-09-17 晚定，CR-20260917-05），
   文档页看质控结果文档（预览与原版 Word 一致、图片可放大、Word/PDF 单份或合并下载，列表上就能直接下载），
   我的（所有人有「历史编辑记录」，找回并修改自己填过的；内部人员多一个「内部管理」板块，四张表像 Excel 一样查看、筛选、导出，只读——CR-20260917-04 / 05）。
2. **登录与可见范围**：统一微信登录 + 手机号；内部人员由实验室在网页工作台按手机号授权，其余都是外部；
   外部不设准入，能填三张表（样本记录信息表、类器官收样记录、石蜡包埋送样记录），提交后由实验室核验有效；外部只看本人和**同组**的记录及其结果。
3. **网页工作台**（仅内部）：所有样本一张总表（批量筛选、内外部标识、切片染色提示），四张表导出 Excel，
   三份 Word（样本质控表 / 类器官质控表 / 类器官质量评分表）在线编辑、传图传附件，完成后同步给送检方。
4. **石蜡包埋与冻存**：染色五选、marker 三选；冻存记代数；-80℃ 超两周提示转液氮；取走/增加都登记，支数可追溯。
   四张表的记录提交后都能改（含冻存登记与冻存数量，改完逐笔剩余不得为负；CR-20260917-04）；取走、补入、转液氮、改删登记只在网页工作台做（CR-20260917-05）。
5. **拍照识别**：拍管壁、袋子或传截图 → 识别 → **只做预填**，填写人核对后提交。
6. **部署运维**：我方代购的阿里云服务器上用 Docker 跑后端、PostgreSQL、工作台；OSS 存文件；每日备份；数据可全量导出。
