为一个微信小程序设计「内部管理」的表格页和它点进去的两个页面，手机竖屏，宽 375，浅色一套主题。出三版：表格、点一行的只读详情、点「修改」之后的修改模式；另外出四个状态帧。这一整套只有中心内部人员看得到。

**产品**：「类器官送检」，湖北江夏实验室类器官研究中心用的送检与样本管理小程序。内部人员从「我的 → 内部管理」点一张表进来，看到的是那张表的全部记录，**像一张 Excel**：四张表在顶上切换，能筛、能左右滑动看全部列、能导出 Excel。表格本身不能改；点一行进只读详情，详情右上角有「修改」，点了才进这张表的填写页改。新增走首页，核验和冻存取用在网页工作台。

**第一版：表格，自上而下**：
1. 导航栏：返回箭头 + 标题 = 当前这张表的全称「样本记录信息表」。
2. 工作表切换条：四个短名并排 —— 样本记录 / 类器官收样 / 石蜡包埋 / -80 冻存。当前的是青绿实底白字小圆角标签，其余中性灰底。
3. 筛选行：左边一个占满剩余宽度的搜索框（占位「搜索 内部编号 / 来源单位 / 供体」），右端一个「核验 ▾」小标签。
4. 一行灰色小字：「共 128 条 · 左右滑动看全部 14 列」。
5. 表格：
   - 表头一行，浅灰底，字小。
   - **第一列冻结**，滑动时不动，右侧有一道 1px 分隔线把它和滚动区分开。冻结格里上下两行：上行是内部编号（等宽，「hli52」），下行是一串很小的字「有效 · 外部」——待核验的那一行这行小字用琥珀色加粗写「待核验 · 外部」。
   - 其余列按模板顺序：来源单位 / 供体姓名（掩码成「刘**」）/ 性别 / 年龄 / 住院号（等宽）…… 屏幕放不下的列靠横向滑动看。
   - 待核验的整行浅黄底，超期的整行浅红底。
   - 画六行，第一行是待核验的浅黄行。
   - **表格在一个宽度被裁掉的容器里横向滑动，页面本身不横向滚动，手机框不能被撑破。**
6. 表格下面一行灰色小字：「点一行看详情，详情里可「修改」 · 浅黄色是待核验」。
7. 底部固定一条：整宽描边次要按钮「导出 Excel」。

**第二版：点一行的只读详情，自上而下**：
1. 导航栏：返回箭头 + 标题「样本记录信息表」+ **右上角一个「修改」**，青绿色文字按钮。
2. 摘要卡：左边内部编号「hli52」（等宽加粗），右边一个绿徽标「有效 · 外部」；下面一行灰色小字「A 医院 · 陈医生 09-09 送检 · 李工 09-12 收样」。
3. 区块标题「送检信息」，只读卡片五行：来源单位 / 供体姓名（详情页显示全名「刘某某」，不掩码）/ 性别 · 年龄 / 住院号（等宽）/ 组织类型。
4. 区块标题「收样信息」，只读卡片八行：收样日期 / 内部编号（等宽）/ 有无固定 / 处理时间 / 质控表 / 细胞活率报告 / 操作人 / 备注（空的显示「—」）。
5. 底部一条灰底小字：「最后修改：李工 · 09-17 10:42」。
- 全页只读：**没有输入框、没有边框、没有底部按钮**，值就是一行文字。二选一的字段直接写「有」「无」，不要画成按钮。

**第三版：点「修改」之后，自上而下**：
1. 导航栏：返回箭头 + 标题「修改样本记录」+ 右上角一行灰色等宽小字「hli52」。
2. 顶部一条浅琥珀底小字条：「正在修改这一条 · 改完点底部「保存」」。
3. 同样两组字段，但这次是能改的表单行：输入框有边框、选择器右端有 `›`、二选一的画成按钮组。
4. 表单下面一行灰色小字：「和首页点表进来的是同一张填写页，只是带着这一条的内容」。
5. 底部固定一条：整宽青绿实底主按钮「保存」。

**另外四个状态帧**：
- **筛完没结果**：表格位置一行灰字「没有符合条件的记录」，下面一个描边小按钮「清空筛选」；表头保留。
- **加载中**：表头保留，下面五行灰色骨架，第一列的骨架宽一点。
- **加载失败**：一行灰字「没能加载，下拉重试」，下面一个描边小按钮「重试」。
- **合作单位送来还没核验的样本的只读详情**：右上角**不出现「修改」**，改成一行灰色小字「核验请到网页工作台」；摘要卡右边是琥珀徽标「待核验 · 外部」。

**不要出现**：表格里的行内编辑、「＋ 新增一行」、核验按钮、批量选择的复选框、删除按钮、分页器（用上拉加载）、右下角悬浮按钮、任何统计数字或角标（筛选行里的核验状态下拉不算）、图表、插画、深色主题。

**视觉语言（沿用这个系统已定稿的其他页面）**：
- 主色青绿 #0E7C7B，浅底 #DDF0EE。
- 页面底 #F3F6F6，卡片与表格 #FFFFFF，分隔线与边框 #E2E9EA。
- 文字三级：#16232B、#5A6B74、#93A1A8。
- 状态色：有效 绿 #2F7D4F（浅底 #DFF1E6），待核验 琥珀 #B7791F（整行底色 #FCF1DA），超期 / 无效 红 #B3362B（整行底色 #FBE4E1）。
- 分层与圆角（视觉方向 A「清爽卡片」）：白卡浮在浅灰底上，靠柔和低阴影分层，卡片不描边；1px #E2E9EA 只用于列表行之间。圆角：卡片 14px、主按钮与控件 12px、按钮组单块 9px、徽标 6px、底部弹层 16px。主按钮带一层很淡的青绿辉光，其他元素不加。
- 编号一律等宽字体：内部编号、送检单号、石蜡块编号、住院号。
- 中文界面，字号克制：表格正文 11px 左右，页面正文 13px 左右，说明文字 10.5px 左右；不要大面积渐变色块。
- 除了表格自己那块横向滑动区，页面不出现横向滚动，手机框不被撑破。

**参考**：当前稿在图廊 `gallery.html#mp-ledger`（表格）、`#mp-ledger-view`（只读详情）、`#mp-ledger-edit`（修改模式），可以在它的基础上改，也可以重新排。入口在「我的」页 `#mp-me-int` 的「内部管理」板块；修改模式用的就是 `#mp-form-a` 那张填写页。
