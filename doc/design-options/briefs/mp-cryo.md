为一个微信小程序设计「-80 冻存」工作表和它点一行弹出的批次详情弹层，手机竖屏，宽 375，浅色一套主题。表格和弹层画在同一张图上（弹层盖在表格上、下面压一层半透明黑蒙层）。另外出四个状态帧。这一页只有中心内部人员看得到。

**产品**：「类器官送检」，湖北江夏实验室类器官研究中心用的送检与样本管理小程序。细胞冻存之后先放 -80℃ 冰箱，放久了要转到液氮长期保存，所以放超过一段时间的批次要被挑出来提醒。取走几支、补回几支都要有登记，剩余支数是算出来的。**小程序上这一页只能看，取走、补入、转液氮、改删登记都在网页工作台做。**

**表格，自上而下**：
1. 导航栏：返回箭头 + 标题「-80 冻存记录」。
2. 工作表切换条：四个短名并排 —— 样本记录 / 类器官收样 / 石蜡包埋 / -80 冻存，当前是「-80 冻存」，青绿实底白字小圆角标签，其余中性灰底。
3. 筛选行：三个并排的小标签 —— 「全部 14」中性灰底、「-80 超期 2」浅红底红字、「液氮 9」中性灰底。当前选中的描一圈。这三个数字是筛选项自带的计数，保留。
4. 表格：
   - 表头一行，浅灰底，字小。
   - **第一列冻结**，滑动时不动，右侧一道 1px 分隔线。冻结格里上下两行：上行是冻存样品名「hli52-GZ-N-P3-EM2-2e5」——很长的一串，等宽字体，在冻结格里**允许折成两行**，不要让它把列撑宽；下行是很小的字「剩 6 / 8 支 · 已超 3 天」，其中「已超 3 天」用红色加粗。
   - 其余列按模板顺序：冻存时间 / 冻存数量/支 / 冻存密度 / 暂存-80度超低温冰箱 / 冻存人 …… 放不下的列靠横向滑动看。
   - **超期的行排在最前，整行浅红底**；没超期的正常白底。画四行，前两行是超期的。
   - 表格在一个宽度被裁掉的容器里横向滑动，页面本身不横向滚动，手机框不能被撑破。
5. 底部固定一条：整宽描边次要按钮「导出 Excel」。

**批次详情弹层（盖在上面，只读）**：
- 半透明黑蒙层压住整页，弹层从底部升起，只有上面两角是圆角。
- 顶行：左边冻存样品名（等宽，字号比正文小一点，一行写完），右边一个红徽标「已超 3 天」。
- 第二行灰色小字：「剩 **6** / 8 支 · -80℃ · P3 · 冻存 2026-08-31」，其中剩余支数那个数字用主文字色加粗。
- 区块标题「取用登记」。
- 登记列表，时间倒序，三到四行，行间 1px 分隔线。每行左边一句「09-14 · 取走 **−2** · 复苏培养 · 李工」（支数变化加粗），右边一个灰色小字「剩 6」。其中一行（「09-05 · 补入 +1 · 同批补冻 · 王工」）在经手人后面跟一个琥珀小标「已改」。
- 底部一条灰底小字：「取走、补入、转液氮与修改登记请到网页工作台。每一笔都写明操作后还剩几支，改过的标「已改」。」
- **弹层里一个操作按钮都没有**：没有取走、补入、转液氮、修改、删除。

**另外四个状态帧**：
- **这个页签下没有记录**：表头保留，下面一行灰字「这个页签下还没有记录」。
- **加载中**：表头保留，下面五行灰色骨架，第一列的骨架宽一点、占两行高。
- **加载失败**：一行灰字「没能加载，下拉重试」，下面一个描边小按钮「重试」。
- **弹层加载中**：弹层顶行与第二行照常显示，「取用登记」下面换成三行灰色骨架。

**不要出现**：取走 / 补入 / 转液氮 / 修改 / 删除这些按钮，右下角悬浮按钮，折线图、饼图、进度环这类图表，温度计或冰箱插画，表格里的行内编辑，批量选择复选框，分页器，深色主题。（筛选行那三个计数不算统计数字，保留。）

**视觉语言（沿用这个系统已定稿的其他页面）**：
- 主色青绿 #0E7C7B，浅底 #DDF0EE。
- 页面底 #F3F6F6，卡片与表格 #FFFFFF，分隔线与边框 #E2E9EA。
- 文字三级：#16232B、#5A6B74、#93A1A8。
- 状态色：有效 绿 #2F7D4F（浅底 #DFF1E6），待核验 / 「已改」小标 琥珀 #B7791F（浅底 #FCF1DA），超期 红 #B3362B（整行底色与徽标底色 #FBE4E1）。液氮位置用蓝 #2B5F9E（浅底 #E1ECF8）。
- 分层与圆角（视觉方向 A「清爽卡片」）：白卡浮在浅灰底上，靠柔和低阴影分层，卡片不描边；1px #E2E9EA 只用于列表行之间。圆角：卡片 14px、主按钮与控件 12px、按钮组单块 9px、徽标 6px、底部弹层 16px。主按钮带一层很淡的青绿辉光，其他元素不加。
- 编号一律等宽字体：冻存样品名称、内部编号。
- 中文界面，字号克制：表格正文 11px 左右，页面正文 13px 左右，说明文字 10.5px 左右；不要大面积渐变色块。
- 除了表格自己那块横向滑动区，页面不出现横向滚动，手机框不被撑破；弹层高度不超过屏幕的三分之二。
