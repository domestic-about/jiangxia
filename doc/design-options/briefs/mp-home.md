为一个微信小程序设计首页，手机竖屏，宽 375，浅色一套主题。出两版：内部人员版、合作单位版；另外出三个状态帧。

**产品**：「类器官送检」，湖北江夏实验室类器官研究中心用的送检与样本管理小程序。底部三个页签：首页、文档、我的。**首页只用来填表**——点哪张表就是进那张表的填写页新增一条；填过的记录到「我的 → 历史编辑记录」里找回和修改。内部人员与合作单位的首页是同一个样子，只是表的张数不同。

**两版都有，自上而下**：
1. 导航栏：标题「类器官送检」，没有返回箭头。
2. 问候行：「李工，上午好」加粗，右端一个身份徽标（内部人员 = 青绿；合作单位 = 蓝）。
3. 身份第二行小字：内部版「类器官研究中心」；合作单位版「A 医院 · 肝胆外科组 · 已核验」。
4. 区块标题行：左边「填写」，右端一行很小的灰字「点表新增一条」。
5. 填写入口宫格（见下）。
6. 宫格下面一行灰色小字：内部版「填过的记录在「我的 → 历史编辑记录」里找回和修改」；合作单位版「提交后由实验室核验；填过的记录在「我的 → 历史编辑记录」」。
7. 底部三个页签：首页（选中，青绿）、文档、我的。

**宫格，每一格长一样**：一个青绿浅底的圆角方块，里面一个字（样 / 类 / 蜡 / 冻），下面是表名全称，再下面一行小字说明。格子是白底圆角卡片，1px 边框。

- **内部人员版**：2×2 四格，顺序固定 ——
  样本记录信息表「组织样本送检与收样」/ 类器官收样记录「收到的类器官」/ 石蜡包埋送样记录「包埋、切片、染色」/ -80 冻存记录「冻存批次」。
- **合作单位版**：三格，没有 -80 冻存记录。前两格并排一行（样本记录信息表「可拍照识别」、类器官收样记录「送类器官」），第三格横向占满整行（石蜡包埋送样记录「挂在自己送检过的样本上」）——占满整行的那一格改成左边方块、右边两行文字的横排，**不要留半宽的孤格**。

**另外三个状态帧**：
- **合作单位还没填单位与组别**：问候行第二行不显示单位组别，改成问候行下方一条可点的浅蓝底提示卡，左边一个小图标，文字「补充单位与组别，可与同组同事互看样本」，右端一个 `›`。
- **加载中**：问候行与宫格都换成灰色骨架块（宫格四个方块骨架），页签栏照常。
- **取不到身份**：宫格一格都不画，那块位置上一行灰字「暂时取不到你的身份，下拉重试」，下面一个描边小按钮「重试」。

**不要出现**：顶部的数字摘要（今日新增 / 待核验 / 冻存超期这类）、「最近记录」列表、「我的送检」入口、入口格子上的角标或小红点、搜索框、轮播图、快捷操作悬浮按钮、任何统计数字、内部编号（合作单位版全程不出现内部编号）、插画、深色主题。

**视觉语言（沿用这个系统已定稿的其他页面）**：
- 主色青绿 #0E7C7B，浅底 #DDF0EE。合作单位的身份色用蓝 #2B5F9E，浅底 #E1ECF8。
- 页面底 #F3F6F6，卡片 #FFFFFF，分隔线与边框 #E2E9EA。
- 文字三级：#16232B、#5A6B74、#93A1A8。已核验 / 有效 绿 #2F7D4F（浅底 #DFF1E6）。
- 分层与圆角（视觉方向 A「清爽卡片」）：白卡浮在浅灰底上，靠柔和低阴影分层，卡片不描边；1px #E2E9EA 只用于列表行之间。圆角：卡片 14px、主按钮与控件 12px、按钮组单块 9px、徽标 6px、底部弹层 16px。主按钮带一层很淡的青绿辉光，其他元素不加。
- 编号类内容一律等宽字体（这一页几乎没有编号，手机号、单号若出现就用等宽）。
- 中文界面，字号克制：正文 13px 左右，说明文字 10.5px 左右；不要大面积渐变色块。
- 全部内容在 375 宽内排完，不出现横向滚动。
