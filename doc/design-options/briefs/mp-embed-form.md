为一个微信小程序设计「石蜡包埋送样记录」的填写页，手机竖屏，宽 375，浅色一套主题。出两版：内部人员版、合作单位版；另外出四个状态帧。两版差别很大，但表单行、按钮组、底部按钮要是同一套。

**产品**：「类器官送检」，湖北江夏实验室类器官研究中心用的送检与样本管理小程序。石蜡包埋是把样本做成蜡块再切片染色的一套工序，中心内部人员要记的东西多，而且**是一张会被反复打开补填的表**——今天填了收样时间，过几天回来填脱水时间，所以不要求一次填完，也不要做成分步向导。合作单位只是「我送一份样本过来做包埋」，只填三项，提交后等中心核验。

**内部人员版，自上而下**：
1. 导航栏：返回箭头 + 标题「石蜡包埋送样记录」。
2. 区块标题「选择样本」。一张卡片一行：左标签「样本」，右边值是内部编号「hli52」（等宽）+「· 刘**」+ 一个 `›`。卡片下面一行灰色小字「只列出已核验有效的样本；选好后自动带出组织收样、组织处理时间」。
3. 区块标题「送样信息」。卡片三行：石蜡块编号（等宽，占位「如 E21-1-2026.09.10」）/ 样本类型（输入，下面出字典联想词）/ 类器官来源类型（输入）。
4. 区块标题「工序时间」。卡片八行：七行日期，顺序固定不能改 —— 组织收样 / 组织处理 / 琼脂糖包埋样本 / 脱水 / 琼脂糖包埋样本送样 / 石蜡包埋 / 切片；第八行是「包埋人」输入。**七行全部可以空着**，空的显示占位「未填」。前两行是选完样本自动带出来的，值右侧各跟一个中性灰小标「已带出，可改」。
5. 区块标题「染色」。一排五个多选按钮：HE染色 / IF染色 / IHC染色 / 其他 / 无染色 —— 多选，但「无染色」和其余四个互斥（选了它，其余全灭）。图上画成选中了 HE染色 和 IHC染色。选「其他」时，按钮排下面多出一个文本框，占位「填具体染色名」。
6. 区块标题「marker 表达」。可增删的多行：每行 = 左边名称输入框（占位「如 Ki67」）+ 右边三个单选按钮（阴性 / 弱表达 / 强表达）+ 行尾一个删除小图标。画两行，第一行「Ki67 · 强表达」，第二行「CK19 · 阴性」。列表底部一行青绿色的「＋ 添加一个 marker」。
7. 区块标题「其他」。卡片两行：操作人 / 备注。
8. 底部固定一条：整宽青绿实底主按钮「保存」；按钮上方一行灰色小字「这张表可以反复打开补填，不要求一次填完」。

**合作单位版，自上而下**：
1. 导航栏一样。
2. 区块标题「选择样本」。卡片一行：左标签「送检样本」，右边值是送检单号「SJ00000127」（等宽）+「· 刘**」+ 一个 `›`。下面一行灰色小字「只列出本人送检过、没有被判无效的样本」。
3. 区块标题「送样信息」。卡片两行：样本类型「组织」/ 类器官来源类型（占位「选填，如 肝类器官」）。
4. 一张浅青绿底的说明卡：第一行加粗「提交后由实验室核验」，下面正文「核验有效后给出石蜡块编号，再陆续补上包埋、切片、染色情况，在样本详情里都看得到。」
5. 底部固定一条：整宽青绿实底主按钮「提交」。
- **合作单位版整组不画的东西**：石蜡块编号、七个工序时间、包埋人、染色、marker 表达、操作人、备注。不是置灰、不是折叠，是根本不渲染，连区块标题都没有。全程不出现内部编号。

**另外四个状态帧**：
- **选择样本的弹层**：底部弹层，上面两角圆角，半透明黑蒙层压住页面。顶部一个搜索框（内部版占位「搜内部编号」，合作单位版占位「搜送检单号」）；下面一行一个样本，左边编号等宽、右边掩码供体姓名与组织类型，再右边一个日期小字。
- **弹层里没有可选的样本**：内部版一行灰字「还没有已核验有效的样本」；合作单位版一行灰字「你还没有送检过样本，先去填样本记录信息表」，下面一个描边小按钮「去填样本记录信息表」。
- **被判无效、改完重新提交（合作单位）**：页面最顶上一条浅红底红字条「无效：所挂样本还没有核验有效，请重新选择」；底部按钮文字改成「重新提交」。
- **保存失败**：底部弹一条深色圆角轻提示「保存失败，请重试」，表单内容不丢。

**按钮组的规矩**：染色和 marker 表达一律画成一排相连的小按钮（选中的是青绿实底白字，没选中的是白底灰字带 1px 边框），**不要用下拉选择、不要用标签云、不要用开关**。

**不要出现**：把七个工序画成步骤条、时间轴或进度环；填写进度百分比；自动推算工序时间；必填星号铺满全表（这张表几乎全可空）；右下角悬浮按钮；任何统计数字；内部编号（合作单位版）；插画；深色主题。

**视觉语言（沿用这个系统已定稿的其他页面）**：
- 主色青绿 #0E7C7B，浅底 #DDF0EE（说明卡的底色用它）。合作单位的身份色用蓝 #2B5F9E，浅底 #E1ECF8。
- 页面底 #F3F6F6，卡片 #FFFFFF，分隔线与边框 #E2E9EA。
- 文字三级：#16232B、#5A6B74、#93A1A8（占位文字用最浅的那级）。
- 状态色：有效 绿 #2F7D4F（浅底 #DFF1E6），待核验 琥珀 #B7791F（浅底 #FCF1DA），无效 红 #B3362B（浅底 #FBE4E1）。
- 分层与圆角（视觉方向 A「清爽卡片」）：白卡浮在浅灰底上，靠柔和低阴影分层，卡片不描边；1px #E2E9EA 只用于列表行之间。圆角：卡片 14px、主按钮与控件 12px、按钮组单块 9px、徽标 6px、底部弹层 16px。主按钮带一层很淡的青绿辉光，其他元素不加。
- 编号一律等宽字体：内部编号、送检单号、石蜡块编号。
- 中文界面，字号克制：正文 13px 左右，说明文字 10.5px 左右；不要大面积渐变色块。
- 全部内容在 375 宽内排完，不出现横向滚动；marker 那一行「名称输入 + 三个按钮 + 删除」要在 375 宽里排得下，排不下就把三个按钮换行放到名称下面，不要让行溢出。

**参考**：合作单位版的当前稿在图廊 `gallery.html#mp-embed-ext`，可以在它的基础上改。内部版没有现成的帧，表单行、按钮组、底部按钮沿用 `#mp-form-a`（样本记录信息表填写页）。中心补完之后合作单位在样本详情里看到的样子见 `#mp-detail-ext`。
