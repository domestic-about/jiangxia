为一个微信小程序设计「文档」页签，手机竖屏，宽 375，浅色一套主题。列表和下载弹层画在同一张图上（弹层盖在列表上、下面压一层半透明黑蒙层）。另外出三个状态帧。

**产品**：「类器官送检」，湖北江夏实验室类器官研究中心用的送检与样本管理小程序。底部三个页签：首页、文档、我的。中心给每一份样本出三份 Word 质控文档——样本质控表、类器官质控表、类器官质量评分表——出好之后送检人在这一页拿。**按样本分组**：一个样本一张卡，卡里列它已经出好的几份文档，每份能单独下，两份以上还能合并预览、合并下载。

**自上而下**：
1. 导航栏：标题「文档」，没有返回箭头。
2. 筛选行：两个并排的小标签 ——「近一月 ▾」（当前选中，青绿浅底青绿字）、「全部类型 ▾」（中性灰底）。
3. 按样本分组的卡片流，按组内最新完成时间倒序。画两张卡：
   - **第一张**（三份都出好了）：
     组标题行：左边送检单号「SJ00000127」（等宽加粗）+「 · 刘**」（列表里供体姓名掩码，保留姓），右边灰色小字「09-16 更新」。
     组内三行，行间 1px 分隔线，每行 = 左边文档名 + 后面跟一个灰色小字完成日期，右端一个描边小按钮「下载」。点这一行的别处是进预览，点「下载」才弹下载弹层。
     组底部两个等宽的描边按钮并排：「合并预览」「合并下载」。
   - **第二张**（只出好一份）：组标题行「SJ00000098 · 赵**」+「09-08 更新」；组内一行「样本质控表 09-08」+「下载」；**组底部不出现合并的两个按钮**（只有一份时没有合并）。
4. 底部三个页签：首页、文档（选中，青绿）、我的。

**组标题行按身份换一种写法**：合作单位看到的是送检单号 +「 · 」+ 掩码供体姓名（上面画的就是这一种）；中心内部人员看到的是内部编号（等宽）+ 来源单位，例如「hli52 · A 医院」。卡片结构、每行的「下载」、组底的两个合并按钮都一样，**只换组标题那一行**。把内部人员的那一张也画出来，和合作单位版并排。

**下载弹层（盖在上面）**：
- 半透明黑蒙层压住整页，弹层从底部升起，只有上面两角是圆角。
- 顶行：左边加粗「下载 · 样本质控表」，右边等宽小字「SJ00000127」。
- 第二行：左边灰字「格式」，右边两个相连的小按钮 PDF（选中，青绿实底白字）/ Word。
- 第三行：两个等宽按钮并排 ——「打开」描边，「发送到微信」青绿实底白字。
- 底部一行灰色小字：「小程序不能直接存进手机文件夹：打开后点右上角可以保存或转发」。

**另外三个状态帧**：
- **空**：列表位置一行灰字「结果出具后会显示在这里」，不配插画、不配按钮。筛选行照常。
- **加载中**：两张卡片换成灰色骨架，每张卡里两三行骨架。
- **加载失败**：一行灰字「没能加载，下拉重试」，下面一个描边小按钮「重试」。

**不要出现**：还没完成的文档或草稿、文档缩略图大图墙、分享到朋友圈、打印、收藏或星标、文件夹树、任何统计数字、插画、深色主题。

**视觉语言（沿用这个系统已定稿的其他页面）**：
- 主色青绿 #0E7C7B，浅底 #DDF0EE。
- 页面底 #F3F6F6，卡片 #FFFFFF，分隔线与边框 #E2E9EA。
- 文字三级：#16232B、#5A6B74、#93A1A8。
- 状态色：已完成 绿 #2F7D4F（浅底 #DFF1E6），草稿 琥珀 #B7791F（浅底 #FCF1DA）。
- 分层与圆角（视觉方向 A「清爽卡片」）：白卡浮在浅灰底上，靠柔和低阴影分层，卡片不描边；1px #E2E9EA 只用于列表行之间。圆角：卡片 14px、主按钮与控件 12px、按钮组单块 9px、徽标 6px、底部弹层 16px。主按钮带一层很淡的青绿辉光，其他元素不加。
- 编号一律等宽字体：送检单号、内部编号。
- 中文界面，字号克制：正文 13px 左右，说明文字 10.5px 左右；不要大面积渐变色块。
- 全部内容在 375 宽内排完，不出现横向滚动；组标题行太长就把供体姓名省略号截断，不要换行。
