# 样本详情（合作单位版）· Claude Design 设计说明

> 用法：打开 claude.ai/design 新建一个设计，把下面「---」之间的整段粘进去。
> 出来的稿子定下之后，把截图或导出的 HTML 放进 `doc/design-options/_from-design/`，回落时替换图廊里的 `#mp-detail-ext`（开关关，默认）与 `#mp-detail-ext-on`（开关开，多一行内部编号）两帧。
> 本机的组件库要同步进 Claude Design 设计系统，需要 Kevin 自己在 Claude Code 里运行 `/design-sync`（模型不能代为调用）。
> 权威：`UI:mp.sample.detail.ext`（REQ-AUTH-005 / 006 / 012 / 013）。

为一个微信小程序设计「样本详情」页，手机竖屏，宽 375，浅色一套主题。这一页是合作单位的人看自己送来的样本被中心处理成什么样了。出两版：开关关（默认）、开关开；另外出四个状态帧。

**产品**：「类器官送检」，湖北江夏实验室类器官研究中心用的送检与样本管理小程序。合作单位的人在「我的 → 历史编辑记录」点一条样本进来这一页，能看到自己送检时填的信息、中心给这份样本做的石蜡包埋情况，以及三份已经出好的质控文档。**这一页是对外的，能看到什么、看不到什么是有边界的**：看得到包埋的工序时间、染色、marker、操作人与包埋人；看不到任何冻存信息，也看不到核验人。标识默认用送检单号，不出现中心的内部编号；中心可以在网页工作台打开一个开关，打开之后这一页多显示一行内部编号——两版只差这一行。

**默认版（开关关），自上而下**：
1. 导航栏：返回箭头 + 标题「样本详情」。
2. 摘要卡：左边送检单号「SJ00000127」（等宽加粗），右边一个绿徽标「有效」；下面一行灰色小字「送检人：陈医生（同组）· 2026-09-09 提交」。
3. 区块标题「送检信息」，只读卡片三行：来源单位「A 医院」/ 供体姓名「刘某某」（详情页显示全名）/ 组织类型「肝组织」。
4. 区块标题「石蜡包埋情况」。一条包埋记录一张卡，画三张：
   - 已经做完的：左边石蜡块编号「E21-1-2026.09.10」（等宽加粗），右边一个青绿徽标「已切片」；第二行灰色小字「石蜡包埋 09-12 · 切片 09-14」；第三行灰色小字「操作人：李工 · 包埋人：周工」；第四行是一排徽标「HE染色」「IHC染色」中性灰底 +「Ki67：强表达」蓝底。
   - 自己交上去还没核验的：左边「石蜡包埋送样」（这时候还没有石蜡块编号），右边一个琥珀徽标「待核验」；第二行灰色小字「09-17 本人提交 · 核验后给出石蜡块编号」。
   - 被判无效的：左边「石蜡包埋送样」，右边一个红徽标「无效」；第二行红色小字「无效：所挂样本还没有核验有效」。
5. 区块标题「质控文档（三份）」，卡片三行，每行 = 左边文档名，右边完成日期小字 + 一个 `›`：样本质控表 09-12 / 类器官质控表 09-15 / 类器官质量评分表 · 合计 80 分 09-16。
6. 页面到此为止，没有底部固定按钮。

**开关开的那一版**：和默认版一模一样，**只在摘要卡里多一行**——那行小字下面加一道 1px 分隔线，再排一行左标签「内部编号」右值「hli52」（等宽）。别的地方一个字都不改。

**另外四个状态帧**：
- **一条包埋记录都没有**：「石蜡包埋情况」那一段只有一行灰字「暂无包埋记录」。
- **一份质控文档都没有**：「质控文档」那一段只有一行灰字「结果出具后会显示在这里」。
- **本人送的、还是「待核验」或「无效」**：摘要卡右边换成琥珀徽标「待核验」或红徽标「无效」；判无效时摘要卡下面多一行红字「无效：缺住院号」，再下面一个整宽描边按钮「修改后重新提交」。（这个按钮**只有本人送的样本上才有**，同组同事送的样本这一页没有任何编辑入口。）
- **加载中 / 加载失败**：加载中，摘要卡与三段各换成灰色骨架；加载失败，一行灰字「没能加载，下拉重试」加一个描边小按钮「重试」。

**不要出现**：任何冻存信息（冻存样品名、支数、位置、超期提示，一处都不能有）、核验人姓名、内部操作日志、导出或下载整页的按钮、跳去别人样本的入口、内部编号（默认那一版）、任何统计数字、插画、深色主题。

**视觉语言（沿用这个系统已定稿的其他页面）**：
- 主色青绿 #0E7C7B，浅底 #DDF0EE。合作单位的身份色用蓝 #2B5F9E，浅底 #E1ECF8（marker 徽标用它）。
- 页面底 #F3F6F6，卡片 #FFFFFF，分隔线与边框 #E2E9EA。
- 文字三级：#16232B、#5A6B74、#93A1A8。
- 状态色：有效 / 已切片 绿 #2F7D4F（浅底 #DFF1E6），待核验 琥珀 #B7791F（浅底 #FCF1DA），无效 红 #B3362B（浅底 #FBE4E1）。
- 分层与圆角（视觉方向 A「清爽卡片」）：白卡浮在浅灰底上，靠柔和低阴影分层，卡片不描边；1px #E2E9EA 只用于列表行之间。圆角：卡片 14px、主按钮与控件 12px、按钮组单块 9px、徽标 6px、底部弹层 16px。主按钮带一层很淡的青绿辉光，其他元素不加。
- 编号一律等宽字体：送检单号、石蜡块编号、内部编号。
- 中文界面，字号克制：正文 13px 左右，说明文字 10.5px 左右；不要大面积渐变色块。
- 全部内容在 375 宽内排完，不出现横向滚动；那一排染色与 marker 徽标放不下时换行，不要溢出。
