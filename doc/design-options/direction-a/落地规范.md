# 类器官送检 · 方向 A「清爽卡片」落地规范

> **读者**：在 `code/miniapp/` 里干活的实现 agent（/zhixing 的 impl 与 QA）。
> **地位**：小程序视觉的唯一规范（CR-20260921-08 起）。内容块与口径仍以 `doc/authority/ui-index.yaml` 为准，这份只管「长什么样」。
> **配套文件**：`tokens.scss`（原样拷到 `src/style/tokens.scss`）、`components.scss`（原样拷到 `src/style/components.scss`）、视觉参照 `../directions/设计方向对比.html` 的方向 A 三张图。
> **不管网页工作台**：工作台沿用若依 plus-ui 默认浅色加主色覆盖，色值与这里同一组（`design-authority.md` §B），不套本文的阴影与圆角。
> **来源**：骨架照东角山方向 A（`dongjiaoshan/doc/design/方向A-落地改造规范.md`），色值沿用本项目既有 token，只改分层、圆角、字号间距并加 wot 映射。

## 0. 落地顺序（SYS-MP-001 起建，后续各域 MP ticket 只套用）

1. 拷 `tokens.scss`、`components.scss` 到 `src/style/`，在 `src/style/index.scss` 里按这个顺序 `@import`，`main.ts` 或 `App.vue` 全局引一次。`src/uni.scss` 保持模板默认，不往里写 token。
2. 全局导航栏：白底黑字（`navigationBarBackgroundColor: "#FFFFFF"`、`navigationBarTextStyle: "black"`），页面底 `backgroundColor: "#F3F6F6"`。写在 unibest 的 `pages.config.ts` 的 `globalStyle`，由它生成 `pages.json`。这是小程序页面配置，允许色值，样式里一律走变量。
3. 自定义 tabbar 与底部固定栏带 `env(safe-area-inset-bottom)`。
4. 各页只用 `wd-*` 组件和 `components.scss` 里的 `.lqg-*` 类，不在页面里各自手写白卡、阴影、圆角。
5. 每做完一类页面，在微信开发者工具里对照方向 A 的参照图看一眼再继续。

## 1. 一句话定义

**白卡浮在浅灰底上，靠柔和低阴影分层，卡片不描边；圆角偏大、留白充足。青绿只用于主按钮、选中、链接和内部身份；表单一律 cell（标签在左、值在右）；日期与选择一律底部弹框。** 规范一致比花哨重要。

## 2. 与旧口径的差异（其余不变）

| 项 | 旧口径（至 9-18） | 方向 A |
|---|---|---|
| 分层 | 不用阴影，1px 边框分层 | **柔和阴影分层，卡片不描边**；1px `--lqg-line` 只用于 cell 之间、表格行之间 |
| 圆角 | 卡片 10 · 按钮 9 · 徽标 5 | 卡片 14 · 主按钮与控件 12 · 搜索框 10 · 按钮组单块 9 · 徽标 6 · 弹层 16 |
| 主按钮 | 实底 | 实底 + `--lqg-shadow-brand` 辉光（只给主按钮） |
| token 位置 | `src/uni.scss` | `src/style/tokens.scss`，挂在 `page` 上，含 `--wot-*` 映射 |
| 字号 | 正文 13、说明 10.5 | cell 标签与值 15、默认 14、表格 13、说明 12、徽标 11 |
| 色值 | §B 那组 | **不变**；新增三个派生值：`--lqg-table-head`、`--lqg-warn-row`、`--lqg-danger-row` |

## 3. Token

全部定义在 `tokens.scss`，这里只列用法；数值以文件为准。

| 组 | 变量 | 用在哪 |
|---|---|---|
| 主色 | `--lqg-primary` / `-deep` / `-soft` / `--lqg-on-primary` | 主按钮、选中块、链接；图标井与选中底用 soft |
| 表面 | `--lqg-bg` / `--lqg-card` / `--lqg-inset` / `--lqg-table-head` | 页面底 / 卡片与底部栏 / 未选中按钮块与搜索框内底 / 表头 |
| 文字 | `--lqg-ink` / `-2` / `-3` | 主 / 次与说明 / 弱、占位、箭头 |
| 分隔 | `--lqg-line` | cell 分隔、表格行线、底部栏顶线 |
| 身份 | `--lqg-ext` / `-soft` | 合作单位徽标、液氮位置 |
| 状态 | `--lqg-warn*` / `--lqg-ok*` / `--lqg-danger*` | 见 §5.6 |
| 阴影 | `--lqg-shadow-sm` / `-md` / `-brand` / `-freeze` | 静止卡片 / 弹层 / 主按钮 / 表格冻结列 |
| 圆角 | `--lqg-radius-card` / `-ctl` / `-field` / `-seg` / `-badge` / `-sheet` | 见 §2 |
| 字号 | `--lqg-fs-*` | 见 §2 |
| 间距 | `--lqg-sp-*`、`--lqg-gutter` 16、`--lqg-gap` 12、`--lqg-cell-h` 52、`--lqg-btn-h` 48 | 屏边距 16，卡片间距 12 |
| 字体 | `--lqg-font` / `--lqg-font-mono` | 系统栈；编号类用 mono（`.lqg-mono`） |

**编号类一律等宽**：内部编号、送检单号、石蜡块编号、冻存样品名称、住院号、手机号。

## 4. wot-design-uni 主题接入

`tokens.scss` 末尾那段 `--wot-*` 变量就是主题接入，挂在 `page` 上即对全部 `wd-*` 生效，**不用** `wd-config-provider`。
接完检查四件：`wd-button type="primary"` 是青绿、`wd-cell-group insert` 圆角 14、`wd-input` 占位是浅灰、`wd-picker` 选中项是青绿。
键名以仓库里 wot-design-uni 1.14 的 `abstracts/variable.scss` 为准；对不上就以代码为准改键名，视觉目标不变。
**别覆盖 `--wot-cell-padding`**：它在 wot 里是单侧 padding，传两个值会污染 cell-group。

## 5. 范式（对应 design-authority.md §C 的组件名）

### 5.1 卡片
`.lqg-card`：白底、圆角 14、`--lqg-shadow-sm`、内边距 14，**不描边**。整块做列表容器时用 `.lqg-card--flush`。
cell 分组直接用 `wd-cell-group insert`（圆角已由 token 设好），组上方的小标题用 `.lqg-gl`。

### 5.2 首页（IdentityBar + EntryTile）
- 问候行：姓名 21/600，后跟身份徽标（`.lqg-tag--internal` 或 `--external`）；第二行 13 次文字。
- 区块标题 `.lqg-sec`：「填写」+ 右侧「点表新增一条」。
- 宫格 `.lqg-grid` + `.lqg-tile`：图标井 `.lqg-well`（42×42、圆角 12、soft 底、线性图标 22）、表名 15/600、说明 12。外部三格时第三格用 `.lqg-tile--full` 横排。**入口上不放角标。**
- 底部说明用 `.lqg-note`，前置时钟图标。

### 5.3 我的（MeHeader + MeList + InternalAdminBlock）
沿用 `#mp-me-int` / `#mp-me-ext` 的结构，外观换成本规范：分组卡用 `.lqg-card--flush`，行首图标井同 5.2 缩小到 32×32、圆角 10；退出登录单独一张卡，红字居中。

### 5.4 Cell 表单（FieldRow）
`wd-cell-group insert` + `wd-cell` / `wd-input align-right` / `wd-picker` / `wd-datetime-picker`：**标签在左、值右对齐**，行高至少 52，cell 之间 1px 分隔从左 14 起。
可点项右侧 `›` 用 `--lqg-ink-3`。日期、选择、选样本一律底部弹框，不做行内展开。必填用 `required`。
多行备注用 `wd-cell vertical` + `wd-textarea`。

### 5.5 按钮组（SegButtons）
模板里写「按钮」的地方一律用 `.lqg-seg`：独立圆角块，未选中 `--lqg-inset` 底次文字，选中 soft 底青绿字加 1px 青绿内描边。二态、三态、染色五态多选都是这一个样子；**不用下拉、不用开关**。

### 5.6 状态徽标（StatusChip）
`.lqg-tag` 浅底深字，按字典值取修饰类，不在页面里写颜色：

| 字典 | 值 | 修饰类 |
|---|---|---|
| `lqg_verify_status` | pending / valid / invalid | `--pending` 琥珀 / `--valid` 绿 / `--invalid` 红 |
| `lqg_submit_source` | internal / external | `--internal` 青绿 / `--external` 蓝 |
| `lqg_doc_status` | draft / published | `--draft` 琥珀 / `--published` 绿 |
| 冻存位置 | minus80 / ln2 / 超期 | 中性（不加徽标） / `--ln2` 蓝 / `--overdue` 红 |
| 识别小标 | 「识别 · 请核对」 | `--ocr` 琥珀 |

身份徽标也用 `.lqg-tag`（不用 `wd-tag`：它非 plain 时文字恒白）。

### 5.7 识别条（OcrBar + OcrMark）
`.lqg-ocr` 一张卡：左「拍照识别」主按钮（实底加辉光），右「从相册选」soft 按钮，高 44、圆角 12；下方 12 弱字说明，末尾「查看识别到的原文」为青绿文字链。
被预填的项在值左侧挂 `.lqg-tag--ocr`，用户改动后消失。识别中两个按钮置灰并出细进度条；失败只换说明文字，不弹窗、不挡表单。

### 5.8 底部固定栏
`.lqg-bar` 白底、顶部 1px 线、带安全区；页面底部垫 `.lqg-bar-spacer`。主操作 `wd-button block type="primary"`，高 48、圆角 12、`--lqg-shadow-brand`；次操作（导出 Excel）用描边样式，不加辉光。

### 5.9 内部管理表格页（SheetTabs + LedgerTable）
- 工作表切换条 `.lqg-sheets`：白底圆角 12 带阴影、内衬 4，选中块青绿实底白字圆角 9。
- 筛选行：搜索框 `wd-search` 或 `.lqg-filter__chip` 同高 38、圆角 10、带阴影。
- 计数行 `.lqg-count`：「共 N 条 · 左右滑动看全部 M 列」。
- 表格装在 `.lqg-ledger` 里横向滑动（`scroll-view scroll-x`），**页面本身不横滚**。表头 `--lqg-table-head` 底 12/600；首列 `.lqg-ledger__fz` 冻结、右缘投影；冻结格两行：编号（mono 13/600）+ 状态小字 11。待核验整行 `--lqg-warn-row`、超期整行 `--lqg-danger-row`。
- 底部只有描边的「导出 Excel」。

### 5.10 底部弹层（CryoBatchSheet / DownloadSheet / 选择器）
`wd-popup position="bottom"`，上两角圆角 16，蒙层 `--lqg-mask`，内容用 `.lqg-sheet`。弹层高不超过屏高三分之二。

### 5.11 空态、加载、失败（EmptyState / LoadingState / ErrorState）
`.lqg-state` 居中：空态一句人话、不配插画；加载用 `.lqg-skel` 骨架块排出列表形状；失败一句人话加描边「重试」。文案以 `ui-index.yaml` 各页写的为准，没写的用「没能加载，下拉重试」。

## 7. 验收清单

- [ ] `src/style/tokens.scss` 与 `doc/design-options/direction-a/tokens.scss` 的变量名集合一致；`src/style/index.scss` 引了它。
- [ ] `src/pages`、`src/components` 里没有色值字面量（样式属性里的 `#xxxxxx`），全部走变量。
- [ ] `wd-button` / `wd-cell` / `wd-picker` 呈青绿，cell 分组圆角 14。
- [ ] 卡片白底、圆角 14、柔阴影、不描边；屏边距 16，卡片间距 12。
- [ ] 表单是标签在左、值在右的 cell；按钮组没被换成下拉或开关；日期与选择走底部弹框。
- [ ] 编号类等宽；状态徽标按 §5.6 取色，页面里不出现颜色值。
- [ ] 表格只在自己的容器里横滑，页面在 390 宽下不横向溢出。
- [ ] 底部栏与 tabbar 带安全区；触控目标不小于 44。
- [ ] 每页的空态、加载态、失败态都有。

## 8. 红线

1. **内容以 ui-index 为准**：不加数字角标、统计、最近记录、装饰插画；外部页面不出现内部编号（开关打开的那一行除外）。
2. **系统字体**，不引入字体文件。
3. 业务页只用 `wd-*` 与 `.lqg-*`，不裸写 view 加 style 去模拟控件。
4. 小程序 wxss 不支持 `:not()` 与 `*` 选择器。
5. 阴影只有 §3 那四档，别自己调新的；主按钮以外不加辉光。
6. 网页工作台不套本规范的阴影与圆角。
