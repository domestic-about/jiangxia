三个方向，挑一个往下做

页面结构和每页的内容块已经定了，以 UI 权威为准，这里只比视觉语言。三个方向画的是同一组代表页：首页、样本记录信息表填写页、内部管理表格页，分别代表入口宫格、长表单、宽表格三种形态，其余页面都能从这三种里推出来。

主色 青绿 #0E7C7B 三个方向都保留，贵方已经看过 字体 只用系统中文字体，小程序加载中文网络字体不现实 组件底座 wot-design-uni 1.14，与东角山同一套 编号类 一律等宽 网页工作台 不在此列

A

清爽卡片 CLEAN CARD

白卡浮在浅灰底上，靠柔和的低阴影分层；圆润、留白足，录入页像手机系统设置。骨架直接沿用东角山方向 A，那套 cell 表单和底部提交栏在真机上调过。

B

实验记录本 LAB LEDGER

把现行视觉口径精修一遍：不用阴影，1px 边框分层，每个区块带一条表头条，数据排得密，像一本实验记录本。贵方看过的稿子就是这个底子，token 与圆角原样不动。

C

沉稳机构 INSTITUTIONAL

深青绿品牌带压住顶部，白色面板压在带上；分区用标题加细线，像质控文档的版式。给合作单位一种「研究中心出的正规系统」的信任感。

  • 自定义导航和字段布局，开发量三个里最大

建议选 A

你说「样式和组件应该都是类似的」，三个方向里只有 A 能把这句话兑现到组件层：东角山的 tokens.scss 映射、.dt-* 范式类和 ui/ 组件层可以大段搬过来，cell 表单与提交栏在真机上已经调过。代价是推翻「小程序不用阴影」这一条口径并调圆角，走一条变更记录即可，内容块一个都不动。

如果你更看重「贵方已经认过的样子一点不变」，选 B；它不用改权威，但组件层要自己做。

选定之后我产出

  1. 落地规范：token 表、组件形态、状态色与字典值的对应、空态加载态失败态，替换 design-authority 的 B 节与 C 节
  2. tokens.scss：项目 token 加 --wot-* 映射，挂在 page 上，一处生效全站
  3. components.scss 范式类与 ui/ 组件清单，照东角山的分层
  4. 同步成 claude.ai/design 的设计系统，后续页面集在那边细化
