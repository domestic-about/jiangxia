为一个微信小程序设计「我的」页，手机竖屏，宽 375，浅色一套主题。出两版：内部人员版、合作单位版。

**产品**：「类器官送检」，湖北江夏实验室类器官研究中心用的送检与样本管理小程序。底部三个页签：首页、文档、我的。首页只用来填表，「我的」用来找回自己填过的记录；内部人员还在这里看四张表的全部记录。

**两版都有，自上而下**：
1. 身份区：头像（没有头像时显示姓的首字）、姓名、身份徽标、手机号中间四位打码（例：139****2046，用等宽字体）。内部人员多一行单位「类器官研究中心」。
2. 「历史编辑记录」一行，带一句说明。内部版说明：「找回自己填过的记录，点进去修改」；合作单位版说明：「本人与同组同事提交的记录」。
3. 《用户协议》《隐私政策》各一行。
4. 最底下「退出登录」。

**只有内部人员版有**：「内部管理」板块。标题旁小字「查看 · 筛选 · 导出」。四个入口：样本记录信息表、类器官收样记录、石蜡包埋送样记录、-80 冻存记录。板块底部一行提示「修改、核验、冻存取用请到网页工作台」。

**只有合作单位版有**：「单位与组别」一行，显示当前值（例：A 医院 · 肝胆外科组）和核验状态徽标（已核验 / 待核验 / 已驳回），小字「改了需要中心重新核验」。

**不要出现**：任何数字角标或统计数字、消息中心、设置项列表、深色主题、内部编号、营销横幅。

**视觉语言（沿用这个系统已定稿的其他页面）**：
- 主色青绿 #0E7C7B，浅底 #DDF0EE。合作单位的身份色用蓝 #2B5F9E，浅底 #E1ECF8。
- 页面底 #F3F6F6，卡片 #FFFFFF，分隔线 #E2E9EA。
- 文字三级：#16232B、#5A6B74、#93A1A8。
- 状态色：已核验 / 有效 绿 #2F7D4F（浅底 #DFF1E6），待核验 琥珀 #B7791F（浅底 #FCF1DA），无效 / 退出登录 红 #B3362B（浅底 #FBE4E1）。
- 编号、手机号一律等宽字体。四张表的入口沿用首页的单字字标：样、类、蜡、冻（青绿浅底方块里一个字）。
- 中文界面，字号克制：正文 13px 左右，说明文字 10.5px 左右；不要大面积渐变色块。
