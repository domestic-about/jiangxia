## 1. 项目简介

给贵方做一套送检小程序和网页工作台：合作单位用小程序填表送检、查看下载结果文档，实验室在网页上批量管理样本、编辑质控文档、管好冻存。

## 2. 业务流程理解

下图是贵方一份样本从小程序送检到结果同步给送检方的主线。

```flow
合作单位小程序送检
[送检信息有效？]
内部编号收样
样本处理与质控
培养与石蜡包埋
网页编辑质控文档
[预览无误？]
结果同步送检方
[送检信息有效？] -> 合作单位小程序送检 : 无效需重新提交
[预览无误？] -> 网页编辑质控文档 : 有误重新编辑
```

## 3. 需求拆解

| 模块 | 需求点 | 解决什么问题 |
|---|---|---|
| 小程序 · 填表 | 四张表在线填写、拍照识别预填、按角色显示可填的表 | 外部人员只填样本记录信息表，内部人员随手录入，信息实时进总表 |
| 小程序 · 文档 | 结果文档列表、预览时图片可放大缩小、Word 或 PDF 下载 | 送检方在手机上直接看结果，和原版 Word 一个样 |
| 小程序 · 登录权限 | 微信加手机号登录、内部人员按手机号授权、外部同组可互看 | 实验室的人权限高，合作单位只看得到本组样本 |
| 网页工作台 · 样本总表 | 所有样本一张总表、批量筛选查询、切片染色情况提示、导出 Excel | 按来源单位随时查、随时导，不用再一个样本一个表 |

### 附：项目难点

**拍照识别信息**

贵方希望拍样本管壁、袋子上的信息或上传截图，自动抓取供体姓名、住院号等信息，省去手工录入。这是本项目技术上最不确定的一环，我方先说清楚难在哪、准备怎么做。

| 难点 | 说明 |
|---|---|
| 手写多 | 管壁、袋子上的信息常是手写，字小、连笔；文字识别对印刷体准确率高，对手写会明显下降 |
| 拍摄条件差 | 样本管是弧面，标签容易变形、反光，冷藏取出后还可能有水汽，照片容易模糊 |
| 版式不统一 | 管壁标签、样本袋、送检单、系统截图排版各不相同，同一项信息出现的位置不固定 |
| 识别后要对号入座 | 识别出来的是一段文字，还要准确拆成供体姓名、住院号、组织类型等字段 |
| 调用费用 | 对手写和杂乱版式效果最好的 AI 识别按次收费，样本量大时要算长期成本 |

**我方的做法**

1. **先用真实照片测效果**：请贵方提供 10-20 张真实照片（管壁、袋子、送检单、截图各几张，可遮挡隐私），我方用不按次收费的识别方案逐张测试，结果书面同步贵方。
2. **识别结果只做预填**：识别出的内容自动填进表单，由填写人核对修改后再提交，识别错了也不会直接进入台账。
3. **效果不够再议 AI**：如果不按次收费的方案对手写识别不够用，我方给出接入 AI 识别的效果对比和按次费用测算，贵方确认后再接入。

### 附：已确认的业务规则

以下规则来自贵方提供的 7 张表格模板、9 月 17 日的微信答复和当天的视频会议，贵方签认后作为开发与验收依据。

**一、小程序**

| 规则 | 说明 |
|---|---|
| 页签 | 首页放四张表的填写入口；中间是文档，放质控等结果文档；最后是「我的」 |
| 登录 | 统一微信登录并授权手机号，不分内部、外部两个入口 |
| 内部人员 | 湖北江夏实验室类器官研究中心的人员，由实验室在网页工作台按手机号授权；可填写全部四张表、查看全部样本 |
| 外部人员 | 内部人员以外的所有人；登录后可填写、修改自己提交的样本记录信息表，填写内容实时进入样本总表，由实验室核验有效后再处理 |
| 可见范围 | 外部人员可以看到与自己样本相关的全部内容，如质控结论、评分、石蜡包埋情况；同单位不同组看不到彼此的样本，同组可以看 |
| 编号显示 | ⚠️ 外部人员看到的石蜡块编号是贵方另取的名称（如 E15-1-2026.07.29），不暴露真实内部编号；其他页面是否向外部显示内部编号，请贵方确认 |
| 拍照识别 | ⚠️ 拍样本管壁、袋子上的信息或上传截图，识别后预填样本信息，核对后提交；识别方案与难点见「附：项目难点」 |
| 文档预览 | 文档列表按时间查找，点开预览，样式与原版 Word 一致，图片可以放大缩小，确认无误后再下载 |
| 文档下载 | 三份 Word 可以单独下载或合并下载，格式可选 Word 或 PDF；外部人员只能查看、下载与自己样本相关的内容 |

**二、网页工作台（仅内部人员使用）**

| 规则 | 说明 |
|---|---|
| 样本总表 | 所有样本集中在一张表里，不按单个样本拆表；可按来源单位等条件批量筛选、查询 |
| 导出 | 四张表都可导出为 Excel，内部人员可导出全部样本信息 |
| 内外部区分 | 按提交人区分：内部人员提交的是内部样本，外部人员提交的是外部样本 |
| 切片染色提示 | 收样记录里提示这个样本做过哪些切片、染色 |
| 质控文档 | 样本质控表、类器官质控表、类器官质量评分表由内部人员在网页上编辑，可上传图片与附件；完成后外部人员在小程序里查看自己样本对应的这三份文档 |

**三、编号、石蜡包埋与冻存**

| 规则 | 说明 |
|---|---|
| 内部编号 | 一个样本从收样到冻存用同一个内部编号 |
| 冻存代数 | 冻存时记录代数，不是每一代都冻存（如 P2 冻存、P3 达不到条件不冻、P7 或 P8 再冻）；冻存命名如 hli39-GZ-N-P3-EM2-2e5 |
| 转液氮提醒 | −80℃ 冻存超过两周，提示转入液氮 |
| 出入库追溯 | 从液氮或 −80℃ 取走要登记，支数随之减少，也可登记增加，全程可追溯 |
| 染色按钮 | HE 染色 / IF 染色 / IHC 染色 / 其他 / 无染色 |
| marker 表达按钮 | 阴性 / 弱表达 / 强表达 |

**四、服务器与运维**

| 规则 | 说明 |
|---|---|
| 服务器与域名 | 云服务器、数据存储、域名由我方代为购买、部署和运维，费用按合同约定按年结算 |
| 数据备份 | 数据库每日自动备份到数据存储，文件与图片同步留存 |
| 数据归属 | 系统数据归贵方所有，贵方可随时要求全量导出，合作结束时由我方协助迁移 |
